# Future sensor plans

[Back to the BMI088 project](../README.md)

The current working implementation is **BMI088 on Arduino UNO Q with ROS 2 Jazzy**. The README and module examples focus on that sensor.

## Planned: BMP581

The next planned addition is the [Bosch Sensortec BMP581 pressure sensor](https://www.bosch-sensortec.com/en/products/environmental-sensors/pressure-sensors/bmp581), for barometric pressure and temperature. No BMP581 driver or ROS pressure publisher is implemented in this repository yet, and no delivery date is promised.

## Which sensor would you like next?

[Open a sensor request](https://github.com/mauringo/bosch-sensortec-ros2-unoq/issues/new?template=sensor-request.yml) with the exact part number, a module link and the ROS measurements you need. If you can test the hardware on an Arduino UNO Q, please mention that.

This remains an independent personal hobby project, not an official Bosch Sensortec integration or support offering.
